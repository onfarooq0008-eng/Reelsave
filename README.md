# ReelSave
Android video downloader.
- TikTok (tikwm.com), X/Twitter (api.fxtwitter.com) and Instagram (public embed page): free, no setup.
- Other sites: add a free FastSaver key or a cobalt instance URL in Settings.

Build: push to GitHub -> Actions -> "Build Debug APK" -> download artifact `ReelSave-debug-apk`.
